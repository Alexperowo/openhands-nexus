# Голос Nexus: распознавание и синтез речи

Служба `ohn-voice`, порт 18020, только на этом ПК (наружу её выводит шлюз). Работает на CPU,
видеокарты остаются моделям. OpenAI-совместимый API, ключ не нужен:

| Адрес | Что делает |
|---|---|
| `POST /v1/audio/transcriptions` | Речь → текст: [GigaAM v3_ctc](https://github.com/salute-developers/GigaAM) (MIT). Любой формат, который читает ffmpeg; длинная запись режется на части |
| `POST /v1/audio/speech` | Текст → речь: [Silero TTS v5.6 ru](https://github.com/snakers4/silero-models) (CC BY-NC 4.0, только некоммерческое использование). Голоса xenia (по умолчанию), baya, aidar, kseniya, eugene; WAV или MP3, 48 кГц; `speed` через ffmpeg |
| `GET /health` | Готовность: обе модели загружены |

Обе модели загружаются при старте службы и лежат в `voice/models/` (не в git):
`.venv/bin/python download_models.py`. Нужны системные `ffmpeg` и `libflite1`.
Юниту задано `MemorySwapMax=0`: при загрузке большой модели служба не уходит в подкачку,
и первая диктовка не ждёт секундами.

Silero падает на звёздочках и на тексте длиннее ~900 символов: служба убирает звёздочки
и синтезирует частями до 700 символов с паузой 0,25 с.

## Произношение латиницы

Silero ru молча выбрасывает всё, что не кириллица: «Я проверил OpenHands работу» звучит как
«Я проверил работу». Поэтому `pronunciation.for_silero` переводит латиницу в русское звучание
до разбиения текста на части.

Порядок: сокращение ссылок, путей и хэшей → словарь привычных терминов → разделение
camelCase/snake_case → чтение заглавных сокращений по буквам → фонемы словаря CMU → кириллица.
Незнакомые слова читает по правилам (G2P) библиотека Flite — системный `libflite1` через
`ctypes`, без сети и новых Python-пакетов. Без неё незнакомое слово даёт явную ошибку с именем
пакета, а не молча пропадает.

| Было | Стало |
| --- | --- |
| OpenHands, GitHub | Оупен Хэндс, Гитхаб |
| Linux, Python, README | Линукс, Пайтон, ридми |
| API, GPU, PR | эй-пи-ай, джи-пи-ю, пи-ар |
| camelCase, snake_case | кэмэл кэйс, снэйк кэйс |
| HTTPServer, getUserName | эйч-ти-ти-пи сервер, гэт юзер нэйм |
| https://github.com/OpenHands/OpenHands | ссылка |
| /home/user/Agents/project/src/service.py | путь к файлу |
| /tmp/service.py | сервис точка пай |
| a1b2c3d, длинный hex, UUID | хэш |

Пути длиннее 50 символов или глубже двух папок — «путь к файлу», у коротких остаётся имя
файла. Очень длинные идентификаторы — «идентификатор». Фонемная кириллица приблизительна;
принятые русские названия задаёт словарь в `pronunciation.py`.

Интерфейс (`ui/src/audio-service.ts`) латиницу не трогает: в обычном режиме чтения он заранее
оставляет от ссылки домен, от пути — имя файла, остальное делает служба.

## Проверки

```sh
.venv/bin/python test_pronunciation.py              # без служб: примеры, G2P, разбиение
.venv/bin/python verify_pronunciation.py --stt --output-dir /tmp/pron   # WAV + распознавание обратно
.venv/bin/python run_tests.py                       # живая служба: TTS → STT, WAV и webm, время
```
