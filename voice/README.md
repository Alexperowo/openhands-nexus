# Произношение латиницы в Silero ru

`service.py:tts_chunks` вызывает `pronunciation.for_silero` **до** ограничения
частей по 700 символов. Ядро OpenHands и интерфейс не менялись.

Порядок: сокращение URL/путей/хэшей → словарь привычных терминов → разделение
camelCase/snake_case → чтение заглавных сокращений → CMU-фонемы → кириллица.
Неизвестные слова обрабатывает letter-to-sound (G2P) Flite. Результаты ограниченно
кэшируются; обращения к глобальному состоянию C-библиотеки защищены блокировкой.

Используется **уже установленный системный `libflite1` версии 2.2-7build1**
(`libflite.so.1`, `libflite_cmulex.so.1`), через стандартный `ctypes`.
Это новая системная зависимость кода; на другой машине её наличие обязательно.
Новых Python-пакетов нет, `.venv`, `pyproject.toml` и `uv.lock` не менялись.
При отсутствии библиотек произношение неизвестного слова завершится явной
ошибкой с названием пакета вместо молчаливого удаления слова.

Выбор сделан для работы без сети: CMU-словарь и G2P уже доступны в Flite,
не требуются загрузка словаря или отдельная нейросеть. Исследованы локальные
исходники Silero внутри `models/v5_6_ru.pt`, установленный
`torchaudio/datasets/cmudict.py`, экспортируемые функции и результаты Flite.
У torchaudio есть загрузчик CMUdict, но сам словарь локально не найден.
Интернет-обзор Silero и других русских TTS не выполнялся из-за запрета сети.

Примеры:

| Было | Стало |
| --- | --- |
| OpenHands, GitHub | Оупен Хэндс, Гитхаб |
| Linux, Python, README | Линукс, Пайтон, ридми |
| API, GPU, PR | эй-пи-ай, джи-пи-ю, пи-ар |
| camelCase, snake_case | кэмэл кэйс, снэйк кэйс |
| HTTPServer, getUserName | эйч-ти-ти-пи сервер, гэт юзер нэйм |
| cache, speech | кэш, спич |
| https://github.com/OpenHands/OpenHands | ссылка |
| /home/user/Agents/project/src/service.py | путь к файлу |
| /tmp/service.py | сервис точка пай |
| a1b2c3d, UUID, длинный hex | хэш (UUID как слово — ю-ю-ай-ди) |

URL и известные доменные зоны заменяются словом «ссылка». Пути без пробелов
длиннее 50 символов или глубже двух компонентов — «путь к файлу»; у коротких
остаётся имя файла. Hex от 16 символов, короткие hex от 7 символов с буквами и
цифрами, UUID — «хэш». Очень длинные идентификаторы — «идентификатор».
Фонемная кириллица приблизительна; словарь служит для принятых русских названий.

Проверка без запущенных служб:

```sh
.venv/bin/python -m unittest -v test_pronunciation
.venv/bin/python -u verify_pronunciation.py --stt --output-dir evidence/pronunciation
```

Обе команды завершились с кодом **0**. Юнит-проверка: 6 тестов, в том числе
30 реальных примеров, параллельный G2P, повторная нормализация, увеличение текста
до разбиения, передача преобразованного текста в модель через `speech`.
Скрипт синтеза запрещает сетевые соединения через Python audit hook;
дополнительно загрузчик GigaAM допускает только существующие локальные файлы.

Доказательства: `evidence/pronunciation/results.json` и четыре WAV в том же
каталоге. Silero v5.6 ru, xenia, CPU, 48000 Гц, фиксированный seed:

| Вход | Длительность | GigaAM v3_ctc |
| --- | --- | --- |
| Я проверил работу. | 1,3625 с | я проверил работу |
| Я проверил OpenHands работу. (без преобразования) | 1,3625 с | я проверил работу |
| Я проверил OpenHands работу. (через `speech`) | 2,0750 с | я проверила опен хэнтс работу |

При исходной латинице WAV **побайтно совпадает** с вариантом без слова:
SHA-256 `418f6fbdfcd2d66b4c03ee61b7d2c2c03f06913eacc29ee6a32f6524c38ef4e9`.
Преобразование добавило **0,7125 с (+52,3%)**. В расширенной фразе GigaAM
распознал: «аопен хэнс и гитхап эй пи вай и джей пи ю пишем код на пайтон».
Это подтверждает появление звучания, но содержит ошибки распознавания,
в частности API/GPU, и не заменяет оценку произношения человеком.
В журнале Silero есть существующий `SyntaxWarning` о `\^` внутри пакета модели;
синтез и проверки завершились успешно. Исходник модели не менялся.

Интерфейс проверен чтением `ui/src/audio-service.ts:178–193` и запуском
его чистых функций `speechText → forSpeech → speechChunks` через Node:
OpenHands, GitHub, Linux, Python, README, PR, API, GPU, JSON, camelCase и
snake_case сохранились при `full=false` и `full=true` (assert, код 0).
`synthesize` передаёт результат в JSON-поле `input`. В Silero исходник
`tts_package/multi_acc_v3_package.py:329–337` удаляет символы вне алфавита.
Вывод: для обычного текста латиница теряется в модели; менять UI не требуется.
В обычном режиме UI заранее оставляет от URL домен, от пути имя файла —
полный путь после этого службе недоступен, но домены также распознаются.

Не проверено: живой интерфейс/HTTP после перезапуска, другие голоса и оценка
человеком на слух. `ohn-voice` не перезапускалась, обращения к :18020/:18030 и
платным API не выполнялись. Новые `*.bak*` не создавались; прежние не тронуты.
Для переноса на чистую машину остаётся учесть системный `libflite1`;
вариант исключительно с зависимостью в `.venv` здесь не реализован.
