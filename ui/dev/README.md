# Проверка плавности Nexus, 24.10.2026

Подготовлены изменения и `dist-next`. **Браузерная приёмка не завершена**:
среда запрещает `listen(127.0.0.1)` (`EPERM`), Chrome завершается на
`shutdown: Operation not permitted`, Firefox — на создании пространства имён.
CLS, длинные кадры, скриншоты и результат axe здесь не получены.
`evidence/before.json`, `after.json`, `ui-results.json`, `chrome.log` и
`test-stream-ui.log` фиксируют блокировку. Нулевые показатели не подставлялись.

## Причины и изменения

- Старый `event-message-with-speech.tsx` сразу передавал весь накопленный пакет в
  `ChatMessage`, обходя `useStreamedText` Canvas. Штатный hook прокрутки включает
  сопровождение растущего текста по флагу этого штатного буфера; наша ветка его
  не устанавливала. Это наблюдение по исходнику, не результат Performance.
- Теперь `stream-buffer.ts` / `use-smooth-text.ts` выдают текст и reasoning по RAF,
  ускоряются при накоплении и не держат кадры, когда буфер пуст. Retry заменяет
  старый префикс; UTF-16 пары не разрываются. История появляется сразу.
- `StableAnswer` сохраняет компонент `ChatMessage`/узел article при delta → final.
  Markdown, картинки, critic и механизм ответвления остаются Canvas.
  Кнопки чтения и заголовок reasoning имеют зарезервированное место.
- Одна новая подмена: `hooks/use-scroll-to-bottom.js`. Она нужна, потому что у
  штатного hook нет props для ResizeObserver и восстановления якоря чтения.
  `scroll-follow.ts` хранит намерение пользователя; `use-scroll-to-bottom.ts`
  корректирует положение после layout до paint, без постоянного цикла RAF.
  Колесо, touch и клавиатура останавливают сопровождение. Якорь узнаётся
  и после замены внутреннего Markdown. Штатная кнопка получает
  имя и подпись «К новым сообщениям» и возвращает сопровождение.
  Подмена прикрыта контрактами `test-providers`, логикой `test-smooth` и сценариями
  браузера `test-smooth-ui` (последние здесь заблокированы).
- `motion.css` — единые длительности 180/220 мс и кривая. Текст не гасится при
  появлении, чтобы не снижать контраст. Движутся только transform/opacity;
  высота и прокрутка не анимируются с задержкой. Изменение высоты disclosure
  компенсирует якорь. При закрытии фон становится inert сразу.
- Настройки → Доступность → Анимации: «Как в системе» (по умолчанию), «Включены»,
  «Уменьшены», «Выключены». Reduced убирает движение/пульсацию/буферизацию,
  оставляя только opacity фона ящика; Off отключает всё. Индикатор работы имеет
  полный цикл 2 секунды. Анимации не перемонтируют live regions и не управляют фокусом.
- Статус занимает постоянное минимальное место. Пустые/завершённые состояния не
  удаляют слот. Неизменившийся опрос сохраняет ссылку на state и activity. Частичный успех
  REST не снимает ошибку до получения состояния беседы.
- `connection-bridge.tsx` передаёт настоящий статус WebSocket из уже существующего
  адаптера поля ввода; дополнительной подмены для этого нет. `connection-state.ts`
  объединяет его с REST. Потеря/восстановление дают одно assertive-объявление на
  переход и локальный Web Audio сигнал, без TTS-сервера. До разрешающего жеста
  сохраняется только последний сигнал. Ошибки повторных попыток не переобъявляются. Первая ошибка WebSocket
  остаётся видимой до OPEN; bootstrap без socket bridge ограничен 15 с.
- `dictation-session.ts` / `use-dictation-with-speech.ts`: ограниченное ожидание
  микрофона и STT (30 с), AbortController, явная отмена, очистка
  tracks, игнорирование позднего результата. Контракт Canvas «вставить текст,
  не отправлять автоматически» сохранён. Свой lifecycle необходим: штатный
  hook не предоставляет отмену транскрипции. После отмены читается ответ,
  пришедший во время диктовки; после обычного завершения прежнее поведение сохранено.
- `audio-controls.tsx`: общая кнопка Stop для ответов/шагов, отмена диктовки и
  включение звука. Stop сохраняет DOM/фокус; отмена возвращает фокус полю ввода.
- В настройках один `main`; новая беседа не получает старую ошибку/статус. Production-конфигурация читает session.env только в
  режиме serve вне стенда; ключ не нужен сборке. Vite 6 игнорирует `envDir:false`:
  проверка выявила это при работе, поэтому dotenv перенаправлен в пустой `dev/no-env`.
  Итоговая сборка проверяется preload-запретом открытия секретных файлов.

## Доказательства и границы

Небраузерные проверки: `test-logic` 62, `test-stream` 7, `test-backend-origin` 2,
`test-providers` 32, `test-smooth` 15 — всего 118. Логи в `evidence/`.
Браузерные проверки не пропускаются и завершаются ошибкой при недоступной среде.
Axe не запускался на странице: движок проверяется только в настоящем Chrome.
Новый пакет для проверки — `axe-core` 4.14.0. `ws` закреплён как devDependency
для мок-сервера; эта версия уже была установлена транзитивно. node_modules не устанавливались.

`evidence/integrity.json`: 15 файлов живой `dist` совпадают с одобренным бэкапом.
Службы и модель не вызывались. Сборка выдаёт прежнее предупреждение о большом
upstream bundle; разбивка bundle находится вне этой порции.
В исходной CSS Canvas нет @font-face, внешние font imports удаляет существующий
плагин. Перестроение шрифта в браузере остаётся непроверенным.

Штатный renderer не объявлен худшим по производительности: замер заблокирован.
Он уже имеет RAF, но не учитывает настройку motion, а ветки streaming/final
меняют дерево компонентов. Свой слой оставлен для стабильного article,
Finish reasoning и чтения. Для проверки решения предусмотрен отдельный A/B.

## Запуск локальной проверки

Команды из `ui`; реальные службы Nexus не нужны. Стенд отвечает на HTTP и
WebSocket сам, в том числе `/llm/running` и `/llm/model/…/health`. Наружу запросы браузера блокируются.
События синтетические, команд на ПК стенд не выполняет.

```sh
node --import ./dev/forbid-secrets.mjs dev/build.mjs /tmp/ohn-ui-after
node dev/server.mjs /tmp/ohn-ui-after 4174
```

Открыть `http://127.0.0.1:4174/conversations/replay`. F8 открывает управление
воспроизведением и отключением связи; после действия панель скрывается, не
закрывает элементы продукта и не меняет viewport. `?controls=1` открывает её сразу.

Исходное состояние восстанавливается только в /tmp из одобренного архива:

```sh
python3 dev/prepare-baseline.py /home/user/Agents/Backups/ohn-ui/ui-src-dist-1024-1540.tgz
node --import ./dev/forbid-secrets.mjs dev/build.mjs /tmp/ohn-ui-before baseline
node --import ./dev/forbid-secrets.mjs dev/build.mjs /tmp/ohn-ui-upstream upstream
node dev/measure.mjs /tmp/ohn-ui-before dev/evidence/before.json
node dev/measure.mjs /tmp/ohn-ui-after dev/evidence/after.json
node dev/measure.mjs /tmp/ohn-ui-upstream dev/evidence/upstream.json
node test-smooth-ui.mjs
node test-stream-ui.mjs
```

Для axe используется установленная devDependency либо `AXE_PATH` к локальному
`axe.min.js`. Здесь доступен `/tmp/ohn-axe/package/axe.min.js`, извлечённый из npm
кэша без сети и установки пакетов. `CHROME_PATH` переопределяет путь браузера.

Матрица: 564×785 / 1280×900, 18 / 28 px, системное reduced-motion включено /
выключено. `measure` сохраняет CLS (session windows), сумму layout shifts,
интервалы RAF >50 мс, Long Animation Frames, переполнение, состояние шрифтов,
сохранность article; для 564×785/28 px сохраняет trace и 4 настоящих кадра.
UI-тест нажимает настоящие Stop/Cancel, проверяет чтение после отмены STT,
позицию при прокрутке вверх, возврат вниз, фокус, настройку Off, ящик, main,
WebSocket-only обрыв и axe с `color-contrast-enhanced`. Никаких нулей при ошибке.
Планшет и TalkBack проверяют руководитель и заказчик.

## Сборка, включение и откат

Итоговая команда (исполнена с preload-запретом секретов):

```sh
NODE_OPTIONS='--import=./dev/forbid-secrets.mjs' npm_config_offline=true npx --no-install vite build --outDir dist-next --configLoader native
```

**Переключение здесь не выполнялось.** После браузерной приёмки руководитель
может атомарно обменять `dist` и `dist-next` из каталога `ui`:

```sh
python3 - <<'PY'
import ctypes, os, pathlib
assert all((pathlib.Path(name) / 'index.html').is_file() for name in ('dist', 'dist-next'))
libc = ctypes.CDLL(None, use_errno=True)
libc.renameat2.argtypes = [ctypes.c_int, ctypes.c_char_p, ctypes.c_int, ctypes.c_char_p, ctypes.c_uint]
if libc.renameat2(-100, b'dist', -100, b'dist-next', 2):
    raise OSError(ctypes.get_errno(), os.strerror(ctypes.get_errno()))
PY
```

Повтор той же команды — откат: прежняя сборка остаётся в `dist-next`.
Механизм exchange/rollback проверен только на собственных каталогах в /tmp,
код завершения 0. Активную вкладку PWA после переключения нужно обновить;
сохранение старых lazy-assets для обновления без перезагрузки не реализовано.
