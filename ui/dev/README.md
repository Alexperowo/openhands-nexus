# Стенд интерфейса

Настоящий интерфейс (App и компоненты Canvas из текущих исходников) против поддельного
сервера, который сам отвечает на все HTTP и WebSocket запросы, в том числе `/llm/running`
и `/llm/model/…/health`, и проигрывает записанную беседу. Службы Nexus не нужны, команд на ПК
стенд не выполняет. Внешние запросы браузера при замерах и тестах обрываются и считаются ошибкой.

Команды — из `ui`:

```sh
node --import ./dev/forbid-secrets.mjs dev/build.mjs /tmp/ohn-ui-replay
node dev/server.mjs /tmp/ohn-ui-replay 4174
```

Открыть `http://127.0.0.1:4174/conversations/replay`. F8 (или `?controls=1` в адресе) —
панель воспроизведения и обрыва связи; после действия она скрывается и не меняет размер окна.

`forbid-secrets.mjs` запрещает сборке открывать файлы ключей; ключ нужен только dev-серверу
Vite (`npm run dev`), а не сборке. Vite 6 ищет dotenv в `envDir` даже при `envDir: false`,
поэтому тот указывает на пустой `dev/no-env`.

## Тесты и замеры

- `node test-smooth-ui.mjs` — Chrome. Сам собирает стенд из текущих исходников во временную
  папку (`OHN_REPLAY_DIR` — взять готовую). Матрица 564×785 и 1280×900 × 18 и 28 px ×
  уменьшение движения вкл/выкл: прокрутка и якорь чтения, сохранность ответа, клавиатура,
  контраст ≥ 7:1, axe с `color-contrast-enhanced`; настоящие «Стоп» озвучки и отмена диктовки,
  фокус, ящик настроек, один `main`, обрыв и восстановление WebSocket.
- `node test-stream-ui.mjs` — Firefox, поток ответа в живом DOM.
- `node dev/measure.mjs <сборка> <out.json>` — CLS, кадры дольше 50 мс, переполнение,
  шрифты; для 564×785/28 px ещё trace и 4 кадра.
- `node --import ./dev/forbid-secrets.mjs dev/build.mjs /tmp/ohn-ui-upstream upstream` —
  та же сборка со штатным отрисовщиком сообщений Canvas (`upstream-event-message.tsx`)
  для сравнения замером.
- `node dev/logic-metrics.mjs` — раздача текста по кадрам на искусственных часах (не браузер).

Скриншоты, axe и отчёты пишутся в `dev/evidence/` (не в git). `CHROME_PATH` и `AXE_PATH`
переопределяют браузер и axe.

## Почему у надстройки свои слои

- Поток ответа: `stream-buffer.ts` и `use-smooth-text.ts` выдают текст и размышления по кадрам
  (RAF), ускоряясь при накоплении, вместо пакетов по сотне символов; пары UTF-16 не рвутся,
  повтор заменяет старый префикс. Узел ответа (`article`) не пересоздаётся при переходе
  от потока к итогу — чтение с экрана не теряет место.
- Прокрутка: подмена `hooks/use-scroll-to-bottom.js` (`use-scroll-to-bottom.ts`,
  `scroll-follow.ts`) — у штатного hook нет ResizeObserver и якоря чтения. Колесо, касание
  и клавиатура останавливают сопровождение; кнопка «К новым сообщениям» его возвращает.
- Движение: `motion.css`/`motion.ts` — 180/220 мс, только transform/opacity; настройка
  «Анимации»: как в системе, включены, уменьшены, выключены.
- Связь: `connection-bridge.tsx` и `connection-state.ts` сводят WebSocket и REST в один статус;
  потеря и восстановление — одно объявление и звуковой сигнал на переход.
- Диктовка: `dictation-session.ts` — ограниченное ожидание микрофона и распознавания (30 с),
  отмена, поздний результат игнорируется; текст вставляется, но не отправляется сам.
- `audio-controls.tsx`: общий «Стоп» озвучки, отмена диктовки, включение звука; статус и кнопки
  звука в одной строке, чтобы на планшете с крупным шрифтом оставалось место для текста.
