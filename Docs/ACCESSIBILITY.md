# Доступность и инклюзивность OpenHands Nexus (Accessibility Guide)

> **Миссия доступности:**  
> Рабочая станция OpenHands Nexus создана и развивается инженером с **первой группой инвалидности по зрению**.  
> Проект доказывает, что современная автономная ИИ-разработка программного обеспечения может быть на 100% доступной, эффективной и комфортной вслепую или в условиях глубокого нарушения зрения.

---

## 1. Философия интерфейса: разработка без визуального контроля

Классические интерфейсы разработки и веб-оболочки для LLM перегружены мелкими графическими контролами, не имеют семантической разметки и требуют постоянного визуального контроля.

В OpenHands Nexus решены ключевые барьеры:
1. **Зрительное переутомление исключено:** Все ключевые действия можно выполнять голосом и с клавиатуры.
2. **Озвучка контекста и мыслей:** Процесс рассуждения модели (Thinking / Chain-of-Thought) и финальный результат озвучиваются в реальном времени.
3. **Безошибочное сенсорное управление:** Интерфейс мобильного PWA спроектирован так, чтобы на планшете или смартфоне кнопки легко находились пальцами без визуального прицеливания.
4. **Полная автономность (Air-Gapped):** Голосовые данные и код обрабатываются строго локально на вашем ПК, не покидая защищённый контур.

## 2. Подсистемы доступности

### 2.1. Экранные дикторы (Screen Readers) и ARIA
Интерфейс Agent Canvas и PWA-надстройка покрыты строгой семантической доступностью:
- **Совместимость с дикторами:**
  - **Windows:** NVDA, JAWS, Экранный диктор Windows (Narrator).
  - **Android:** Google TalkBack.
- **Живые регионы (`aria-live="polite"`):**
  - Оповещения о смене активного профиля (`⚡ Qwen 3.8 (Автономный) · Medium`).
  - Статусы инференса (`Модель думает...`, `Генерация кода завершена`).
  - Сообщения об ошибках и предупреждения VRAM.
  - Живые оповещения не прерывают текущую речь диктора, а встают в очередь вежливого зачитывания.
- **Чёткие фокусные кольца (`:focus-visible`):**
  - Для слабовидящих разработчиков предусмотрена высококонтрастная неоновая подсветка фокуса с достаточным коэффициентом контрастности (более 7:1 к фону).

---

### 2.2. Автономный нейро-голосовой мост (Local Voice Bridge, порт 18002)
Встроенный локальный голосовой сервис ([`local-voice/service.py`](../local-voice/service.py)) обеспечивает полный цикл речевого взаимодействия:

1. **Распознавание русской речи (STT) — FUTO GigaAM v3:**
   - Высокоточная нейросеть, дообученная на русскоязычную речь и специализированную техническую лексику (Git, Python, Docker, API, CUDA).
   - Задержка отклика (latency) всего **100–300 мс** на локальном CPU/GPU.
   - Микрофон активируется нажатием крупной сенсорной кнопки или сочетанием клавиш.
2. **Двухдвижковая озвучка (Dual-Engine TTS):**
   - **Supertonic LAN TTS:** Нейросетевой синтез речи высокого разрешения, работающий на локальном сервере.
   - **Native Android / Web SpeechSynthesis:** Мгновенная системная озвучка через штатные голоса смартфона/планшета (например, Samsung TTS или Google TTS) без нагрузки на сеть.
3. **Функция прерывания (Barge-in / Stop):**
   - При получении нового ввода или нажатии клавиши Stop озвучка мгновенно прерывается, освобождая звуковой канал.
4. **Ручная и автоматическая озвучка:**
   - Каждое сообщение ассистента снабжено крупной кнопкой повторного воспроизведения (`🔊 Озвучить`).
   - Доступен режим `Auto-TTS`, который автоматически зачитывает поступающий ответ сразу по завершении генерации.

---

### 2.3. Сенсорная эргономика для планшетов и смартфонов (WCAG 2.5.5 Level AAA)
Мобильный пульт управления PWA адаптирован для управления на ощупь:

* **Крупногабаритные сенсорные области:**
  - Все ключевые интерактивные элементы (кнопка микрофона, отправка, переключатель моделей) имеют физический размер **не менее 48×48 px** (до **52 px** на планшетах).
  - Это полностью соответствует строжайшему уровню стандарта **WCAG 2.5.5 Target Size (Enhanced, Level AAA)**.
* **Исключение случайных нажатий:**
  - Вокруг кнопок соблюдены защитные отступы (padding/margin), предотвращающие ложное срабатывание соседних элементов при тактильном поиске кнопки пальцем.
* **Защита от сдвига разметки:**
  - Использование динамических единиц `100dvh` и обработка событий `visualViewport` предотвращают схлопывание или уплывание селектора профилей при вызове экранной клавиатуры.

---

### 2.4. Полная клавиатурная навигация (Keyboard-First)
Любая операция на станции может быть выполнена исключительно с клавиатуры:
* `Tab` / `Shift+Tab` — последовательный переход между элементами управления в логическом порядке.
* `Enter` / `Space` — активация кнопок, раскрытие выпадающих списков профилей.
* `Escape` — быстрое закрытие диалогов, отмена выбора, сброс фокуса в поле ввода задачи.
* Доступны быстрые клавиши отправки задачи и прерывания генерации.

## 3. Рекомендации по настройке рабочего места

### Для пользователей NVDA (Windows)
1. Рекомендуется включить автоматическое чтение динамических изменений (`NVDA -> Параметры -> Просмотр документа -> Автоматически сообщать об изменениях в динамических областях`).
2. При работе с кодом в окне терминала OpenHands используйте режим обзора NVDA (`NVDA + Пробел`).

### Для пользователей TalkBack (Android / Samsung Galaxy Tab)
1. Запустите OpenHands Nexus как PWA: откройте `https://<LAN-IP>:8443`, нажмите «Добавить на главный экран».
2. В интерфейсе PWA TalkBack озвучивает селектор профилей как «Кнопка выбора рабочего профиля, текущий: Qwen 3.8 Medium».
3. Двойное касание с удержанием позволяет легко перемещаться по списку профилей.
