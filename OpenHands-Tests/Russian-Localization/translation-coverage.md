## Распределение по функциональным разделам

### 1. Домашний экран и навигация (`HOME$*`, `NAV$*`, `SIDEBAR$*`)
- Заголовок: **«Давайте начнём разработку!»** (`HOME$LETS_START_BUILDING`)
- Подзаголовок: **«Что вы хотите создать?»** (`HOME$WHAT_DO_YOU_WANT_TO_BUILD`)
- Кнопка рабочей области: **«Открыть рабочую область»** (`HOME$OPEN_WORKSPACE`)
- Кнопка плагинов: **«Плагины»** (`HOME$PLUGINS`)
- Боковое меню: **«Поиск команд»**, **«Новый чат»**, **«Настроить»**, **«Диалоги»**
- Чек-лист быстрого старта: **«Начало работы»**, **«Добавить API-ключ LLM»**, **«Запланировать задачу»**, **«Настроить вашего агента»**, **«Подключить MCP-интеграцию»**

### 2. Настройки системы (`SETTINGS$*`)
- Вкладка **«Агент»**: шаблоны конфигураций, доступные профили, кнопка «Добавить профиль агента».
- Вкладка **«Языковая модель»**: выбор моделей, API-ключи, список подключений провайдеров.
- Вкладка **«Конденсатор»**: настройки сокращения контекста, алгоритм сжатия.
- Вкладка **«Контекст агента»**: навыки, системные промпты, память агента.
- Вкладка **«Проверка»**: верификация действий агента (critic).
- Вкладка **«Приложение»**: селектор **«Язык: Русский»**, цветовая тема, настройки Git-идентичности (имя, email), звуковые уведомления, аналитика.
- Вкладка **«Секреты»**: именованные переменные окружения, безопасное хранение ключей.

### 3. Автоматизации (`AUTOMATIONS$*`, `AUTOMATE$*`)
- Заголовок: **«Синхронизация Git»**, **«Добавить автоматизацию»**.
- Фильтры и поиск: **«Поиск автоматизаций...»**, **«Фильтры»**.
- Экран пустого состояния: **«Автоматизации не настроены. Начните новый диалог и попросите OpenHands создать автоматизацию...»**.

### 4. Протокол контекста модели MCP (`SETTINGS$MCP_*`, `MCP$*`)
- Заголовок: **«Протокол контекста модели (MCP)»**.
- Описание: **«Добавьте серверы Model Context Protocol, чтобы расширить возможности вашего агента. Нажмите на любой сервер ниже, чтобы установить его.»**.
- Действия: **«Добавить пользовательский сервер»**, **«Поиск серверов MCP»**, **«Тест соединения»**, статус **«Ещё не проверено»** / **«Подключено»**.

### 5. Диалоги и рабочая область (`CONVERSATION$*`, `WORKSPACE$*`)
- Элементы чата: отображение стоимости токенов, тайминги, остановка генерации.
- Вкладки рабочей области: браузер, терминал, редактор файлов, планировщик.
- Модальные окна: подтверждение удаления диалогов, восстановление сессий.

### 6. Профили рассуждения (Reasoning Aliases)
- **Direct**: «Без рассуждения» (внутреннее значение: `none` / thinking off)
- **Low**: «Низкая» (внутреннее значение: `low`)
- **Medium**: «Средняя» (внутреннее значение: `medium`)
- **XHigh**: «Максимальная» (внутреннее значение: `xhigh`)
