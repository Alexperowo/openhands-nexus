# Contributing to OpenHands Nexus

Спасибо за интерес к проекту **OpenHands Nexus**!

## Архитектурные принципы

Проект создаётся как стабильный локальный **AI Remote Control для Windows 11** с управлением с ПК и мобильных устройств (Android/PWA) без технической сложности для пользователя.

1. **Сохранение простоты для конечного пользователя:** управление станцией не должно требовать от пользователя работы в терминале или настройки моделей вручную.
2. **Нативная производительность:** модели запускаются нативно через llama-swap с поддержкой CUDA для максимальной скорости (MTP до 63 токенов/с на RTX 2080 Ti 22GB) без виртуализационного оверхеда.
3. **Безопасность и автономность:** 100% локальная работа (offline-first), изоляция ключей, сертификатов и сессий.
4. **Доступность (Accessibility):** поддержка экранных дикторов (ARIA), тач-таргеты не менее 44x44px (WCAG 2.5.5), устойчивость к вызову экранной клавиатуры.

## Процесс внесения изменений

1. Создайте ветку для ваших изменений:
   `ash
   git checkout -b feature/my-feature
   `
2. Убедитесь, что все тесты проходят:
   `cmd
   CHECK-DEPENDENCIES.cmd
   `
3. Проверьте форматирование кода и отсутствие секретов в коммитах.
4. Сформируйте Pull Request с подробным описанием изменений и доказательствами тестирования (скриншоты, логи, замеры).
