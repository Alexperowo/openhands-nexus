## 1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

### Что это такое
**OpenHands Nexus** — локальная автономная мультимодельная рабочая станция для AI-разработки, работающая на Windows 11 с поддержкой CUDA.

### Назначение (по определению пользователя)
> Стабильный локальный AI Remote Control для Windows 11, которым можно управлять с компьютера и Android без технической настройки моделей, с Working Profiles, Team-Full, голосом, PWA, accessibility.

### Ключевые возможности
- Оркестрация 3 локальных LLM моделей
- Адаптивное голосовое управление (STT/TTS)
- Защищённый мобильный PWA Remote Control
- Динамический Thinking UX
- Рабочие профили (соло, тандемы, команда)

### Технический стек
| Компонент | Технология |
|-----------|------------|
| Ядро | Python (61.9%) |
| Скрипты управления | PowerShell (25.4%) |
| Фронтенд | JavaScript (7.1%), TypeScript (3.1%) |
| Стили | CSS (1.8%) |
| Пакетные файлы | Batchfile (0.7%) |
| Среда | Windows 11, CUDA, Node.js v24 |

### ⚠️ Проблемы архитектуры

#### Проблема 1: Жёстко заданный IP-адрес
**Где:** HTTPS LAN Gateway, Leaf SAN сертификат  
**Что:** `192.168.0.14` захардкожен в конфигурации  
**Почему плохо:** При смене сети или IP система перестаёт работать  
**Как исправить:**
```javascript
// Вместо хардкода:
const HARDCODED_IP = '192.168.0.14';

// Использовать динамическое определение:
import os from 'os';

function getLocalIP() {
    const interfaces = os.networkInterfaces();
    for (const name of Object.keys(interfaces)) {
        for (const iface of interfaces[name]) {
            if (iface.family === 'IPv4' && !iface.internal) {
                return iface.address;
            }
        }
    }
    return 'localhost';
}

const LOCAL_IP = getLocalIP();
```

#### Проблема 2: Отсутствие контейнеризации
**Где:** Весь стек  
**Что:** Все сервисы работают как нативные Windows-процессы  
**Почему плохо:** Нет изоляции, сложно управлять зависимостями  
**Как исправить:** Рассмотреть варианты:
- **Вариант A:** WSL2 для Linux-компонентов
- **Вариант B:** Docker Compose для сервисов
- **Вариант C:** Минимальный — использовать PM2 для Node.js процессов

#### Проблема 3: Монолитность скриптов управления
**Где:** 8 различных `.cmd` файлов в корне  
**Что:** Каждый скрипт делает одну операцию  
**Почему плохо:** Пользователю нужно помнить 8 команд  
**Как исправить:** Создать единый CLI:
```batch
@echo off
```

## 3. КРИТИЧЕСКИЕ ПРОБЛЕМЫ БЕЗОПАСНОСТИ

### 🔴 КРИТИЧНО: Отсутствие аутентификации в LAN API

**Где:** Все эндпоинты на порту 8443  
**Что:** Любой в локальной сети может получить доступ к `/api/working-profiles`, `/voice-api/*`  
**Риск:** Высокий — любой в вашей сети может управлять вашей AI-станцией

**Как исправить:**

#### Шаг 1: Добавить токен аутентификации
```javascript
// В openhands-pwa/server.js или аналогичном файле

import crypto from 'crypto';

// Генерация токена при первом запуске
function generateAuthToken() {
    return crypto.randomBytes(32).toString('hex');
}

// Middleware для проверки токена
function authMiddleware(req, res, next) {
    const authHeader = req.headers.authorization;
    const token = authHeader && authHeader.split(' ')[1]; // Bearer TOKEN
    
    if (!token) {
        return res.status(401).json({ error: 'Unauthorized: No token provided' });
    }
    
    if (token !== process.env.AUTH_TOKEN) {
        return res.status(403).json({ error: 'Forbidden: Invalid token' });
    }
    
    next();
}

// Применение ко всем API роутам
app.use('/api', authMiddleware);
app.use('/voice-api', authMiddleware);
```

#### Шаг 2: Хранить токен в защищённом месте
```javascript
// config/auth.js
import fs from 'fs';
import path from 'path';
import os from 'os';

const TOKEN_FILE = path.join(os.homedir(), '.openhands', 'auth.token');

export function getAuthToken() {
    if (fs.existsSync(TOKEN_FILE)) {
        return fs.readFileSync(TOKEN_FILE, 'utf8').trim();
    }
    
    const token = generateAuthToken();
    fs.writeFileSync(TOKEN_FILE, token, { mode: 0o600 });
    return token;
}
```

#### Шаг 3: Обновить PWA для использования токена
```javascript
// В Service Worker или основном коде PWA
async function apiRequest(url, options = {}) {
    const token = await getStoredToken(); // Из localStorage или настройки
    
    const response = await fetch(url, {
        ...options,
        headers: {
            ...options.headers,
            'Authorization': `Bearer ${token}`
        }
    });
    
    if (response.status === 401) {
        // Показать экран ввода токена
        showAuthScreen();
        return null;
    }
    
    return response;
}
```

### 🔴 КРИТИЧНО: Отсутствие логирования подключений

**Где:** Все сетевые сервисы  
**Что:** Нет аудита кто и когда подключался  
**Риск:** Невозможно отследить несанкционированный доступ

**Как исправить:**
```javascript
// middleware/logger.js
import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const LOG_DIR = path.join(__dirname, 'logs');
const ACCESS_LOG = path.join(LOG_DIR, 'access.log');

// Создаём директорию если не существует
if (!fs.existsSync(LOG_DIR)) {
    fs.mkdirSync(LOG_DIR, { recursive: true });
}

export function accessLogger(req, res, next) {
    const timestamp = new Date().toISOString();
    const ip = req.ip || req.connection.remoteAddress;
    const method = req.method;
    const url = req.url;
    const userAgent = req.headers['user-agent'] || 'Unknown';
    
    const logEntry = `[${timestamp}] ${ip} ${method} ${url} "${userAgent}"\n`;
    
    fs.appendFile(ACCESS_LOG, logEntry, (err) => {
        if (err) console.error('Failed to write access log:', err);
    });
    
    next();
}

// Применение в сервере
app.use(accessLogger);
```

### 🔴 КРИТИЧНО: Хранение приватных ключей

**Где:** Сертификаты для HTTPS  
**Что:** Неясно как защищены приватные ключи  
**Риск:** Компрометация ключей позволяет расшифровать трафик

**Как исправить:**

#### Вариант 1: Использовать DPAPI Windows (рекомендуется)
```javascript
// crypto/dpapi.js
import { exec } from 'child_process';
import { promisify } from 'util';

const execAsync = promisify(exec);

export async function encryptKey(keyData) {
    // Используем PowerShell для шифрования через DPAPI
    const script = `
        $key = [Convert]::FromBase64String('${keyData.toString('base64')}')
        $encrypted = [System.Security.Cryptography.ProtectedData]::Protect(
            $key, $null, [System.Security.Cryptography.DataProtectionScope]::CurrentUser
        )
        [Convert]::ToBase64String($encrypted)
    `;
    
    const { stdout } = await execAsync(`powershell -Command "${script}"`);
    return stdout.trim();
}

export async function decryptKey(encryptedData) {
    const script = `
        $encrypted = [Convert]::FromBase64String('${encryptedData}')
        $decrypted = [System.Security.Cryptography.ProtectedData]::Unprotect(
            $encrypted, $null, [System.Security.Cryptography.DataProtectionScope]::CurrentUser
        )
        [Convert]::ToBase64String($decrypted)
    `;
    
    const { stdout } = await execAsync(`powershell -Command "${script}"`);
    return Buffer.from(stdout.trim(), 'base64');
}
```

#### Вариант 2: Минимальный — зашифрованная папка
```javascript
// crypto/key-storage.js
import crypto from 'crypto';
import fs from 'fs';
import path from 'path';
import os from 'os';

const KEYS_DIR = path.join(os.homedir(), '.openhands', 'keys');
const ALGORITHM = 'aes-256-gcm';

// Пароль должен запрашиваться у пользователя или храниться в переменных окружения
export function encryptKeyFile(keyPath, password) {
    const key = fs.readFileSync(keyPath);
    const salt = crypto.randomBytes(16);
    const iv = crypto.randomBytes(12);
    const passwordHash = crypto.scryptSync(password, salt, 32);
    
    const cipher = crypto.createCipheriv(ALGORITHM, passwordHash, iv);
    let encrypted = cipher.update(key);
    encrypted = Buffer.concat([encrypted, cipher.final()]);
    const authTag = cipher.getAuthTag();
    
    // Сохраняем: salt + iv + authTag + encrypted
    const result = Buffer.concat([salt, iv, authTag, encrypted]);
    fs.writeFileSync(keyPath + '.enc', result, { mode: 0o600 });
    
    // Удаляем оригинальный ключ
    fs.unlinkSync(keyPath);
}
```

### 🟡 ВАЖНО: Rate Limiting для API

**Где:** Все эндпоинты  
**Что:** Нет ограничения на количество запросов  
**Риск:** DoS атака в локальной сети

**Как исправить:**
```javascript
// middleware/rate-limit.js
const requestCounts = new Map();
const WINDOW_MS = 60 * 1000; // 1 минута
const MAX_REQUESTS = 100; // Максимум запросов в минуту

export function rateLimiter(req, res, next) {
    const ip = req.ip || req.connection.remoteAddress;
    const now = Date.now();
    
    if (!requestCounts.has(ip)) {
        requestCounts.set(ip, { count: 1, resetTime: now + WINDOW_MS });
        return next();
    }
    
    const record = requestCounts.get(ip);
    
    // Сброс счётчика если окно прошло
    if (now > record.resetTime) {
        requestCounts.set(ip, { count: 1, resetTime: now + WINDOW_MS });
        return next();
    }
    
    record.count++;
    
    if (record.count > MAX_REQUESTS) {
        return res.status(429).json({ 
            error: 'Too many requests',
            retryAfter: Math.ceil((record.resetTime - now) / 1000)
        });
    }
    
    next();
}

// Очистка старых записей каждые 5 минут
setInterval(() => {
    const now = Date.now();
    for (const [ip, record] of requestCounts) {
        if (now > record.resetTime) {
            requestCounts.delete(ip);
        }
    }
}, 5 * 60 * 1000);
```

```powershell
# openhands.ps1 - единый скрипт управления
param(
    [Parameter(Mandatory=$true)]
    [ValidateSet('start', 'stop', 'restart', 'setup', 'backup', 'restore', 'diagnose', 'status')]
    [string]$Action,
    
    [switch]$Verbose
)

$ErrorActionPreference = "Stop"
$OpenHandsRoot = $PSScriptRoot
$LogsDir = Join-Path $OpenHandsRoot "logs"

# Создание директории логов
if (-not (Test-Path $LogsDir)) {
    New-Item -ItemType Directory -Path $LogsDir -Force | Out-Null
}

function Write-Log {
    param([string]$Message, [string]$Level = "INFO")
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    $logMessage = "[$timestamp] [$Level] $Message"
    Write-Host $logMessage
    Add-Content -Path (Join-Path $LogsDir "openhands.log") -Value $logMessage
}

function Start-OpenHands {
    Write-Log "Starting OpenHands Nexus services..."
    
    # Проверка портов
    $ports = @(8000, 8443, 18000, 18002, 8080)
    foreach ($port in $ports) {
        $connection = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue
        if ($connection) {
            Write-Log "Port $port is already in use by PID $($connection.OwningProcess)" -Level "ERROR"
            return $false
        }
    }
    
    # Запуск сервисов
    try {
        Write-Log "Starting llama-swap router on port 8080..."
        Start-Process -FilePath "llama-swap" -ArgumentList "--port 8080" -WindowStyle Hidden
        
        Write-Log "Starting voice bridge on port 18002..."
        Start-Process -FilePath "python" -ArgumentList "local-voice/main.py" -WindowStyle Hidden
        
        Write-Log "Starting agent server on port 18000..."
        Start-Process -FilePath "python" -ArgumentList "-m openhands.server" -WindowStyle Hidden
        
        Write-Log "Starting agent canvas on port 8000..."
        Start-Process -FilePath "node" -ArgumentList "openhands-pwa/agent-canvas.js" -WindowStyle Hidden
        
        Write-Log "Starting LAN gateway on port 8443..."
        Start-Process -FilePath "node" -ArgumentList "openhands-pwa/gateway.js" -WindowStyle Hidden
        
        Write-Log "All services started successfully" -Level "SUCCESS"
        return $true
    }
    catch {
        Write-Log "Failed to start services: $_" -Level "ERROR"
        return $false
    }
}

function Stop-OpenHands {
    Write-Log "Stopping OpenHands Nexus services..."
    
    $processes = @(
        @{ Name = "llama-swap"; Pattern = "llama-swap" },
        @{ Name = "Voice Bridge"; Pattern = "local-voice/main.py" },
        @{ Name = "Agent Server"; Pattern = "openhands.server" },
        @{ Name = "Agent Canvas"; Pattern = "agent-canvas.js" },
        @{ Name = "LAN Gateway"; Pattern = "gateway.js" }
    )
    
    foreach ($proc in $processes) {
        $found = Get-Process | Where-Object { 
            $_.CommandLine -like "*$($proc.Pattern)*" 
        } -ErrorAction SilentlyContinue
        
        if ($found) {
            Write-Log "Stopping $($proc.Name)..."
            $found | Stop-Process -Force
        }
    }
    
    Write-Log "All services stopped" -Level "SUCCESS"
}

# Основная логика
switch ($Action) {
    'start' { Start-OpenHands }
    'stop' { Stop-OpenHands }
    'restart' { 
        Stop-OpenHands
        Start-Sleep -Seconds 2
        Start-OpenHands 
    }
    'setup' { 
        Write-Log "Running setup..."
        & (Join-Path $OpenHandsRoot "SETUP-OPENHANDS-LOCAL.ps1")
    }
    'backup' { 
        Write-Log "Creating backup..."
        & (Join-Path $OpenHandsRoot "BACKUP-OPENHANDS.ps1")
    }
    'restore' { 
        Write-Log "Restoring from backup..."
        & (Join-Path $OpenHandsRoot "RESTORE-OPENHANDS.ps1")
    }
    'diagnose' { 
        Write-Log "Running diagnostics..."
        & (Join-Path $OpenHandsRoot "DIAGNOSTICS-OPENHANDS-LOCAL.ps1")
    }
    'status' {
        Write-Log "Checking service status..."
        # Реализация проверки статуса
    }
}
```

### Проблема 1: Нет индикатора прогресса при запуске

**Где:** `START-OPENHANDS-LOCAL.cmd`  
**Что:** Пользователь не видит прогресс запуска 5 сервисов  
**Как исправить:**

```powershell
# start-openhands.ps1 с прогресс-баром
function Show-Progress {
    param(
        [string]$Activity,
        [string]$Status,
        [int]$PercentComplete
    )
    Write-Progress -Activity $Activity -Status $Status -PercentComplete $PercentComplete
}

function Start-OpenHands {
    $services = @(
        @{ Name = "llama-swap Router"; Port = 8080; Command = "llama-swap --port 8080" },
        @{ Name = "Voice Bridge"; Port = 18002; Command = "python local-voice/main.py" },
        @{ Name = "Agent Server"; Port = 18000; Command = "python -m openhands.server" },
        @{ Name = "Agent Canvas"; Port = 8000; Command = "node openhands-pwa/agent-canvas.js" },
        @{ Name = "LAN Gateway"; Port = 8443; Command = "node openhands-pwa/gateway.js" }
    )
    
    $total = $services.Count
    $current = 0
    
    foreach ($service in $services) {
        $current++
        $percent = [math]::Round(($current / $total) * 100)
        
        Show-Progress -Activity "Starting OpenHands Nexus" `
                      -Status "Starting $($service.Name)..." `
                      -PercentComplete $percent
        
        Write-Host "[$current/$total] Starting $($service.Name) on port $($service.Port)..."
        
        try {
            # Проверка занятости порта
            $portInUse = Get-NetTCPConnection -LocalPort $service.Port -ErrorAction SilentlyContinue
            if ($portInUse) {
                Write-Warning "Port $($service.Port) is already in use"
                continue
            }
            
            # Запуск сервиса
            Start-Process -FilePath $service.Command.Split(' ')[0] `
                         -ArgumentList $service.Command.Split(' ')[1..10] `
                         -WindowStyle Hidden
            
            # Ожидание запуска
            $timeout = 30
            $elapsed = 0
            while ($elapsed -lt $timeout) {
                Start-Sleep -Seconds 1
                $elapsed++
                
                $connection = Test-NetConnection -ComputerName localhost -Port $service.Port -ErrorAction SilentlyContinue
                if ($connection.TcpTestSucceeded) {
                    Write-Host "✓ $($service.Name) started successfully" -ForegroundColor Green
                    break
                }
            }
            
            if ($elapsed -ge $timeout) {
                Write-Warning "$($service.Name) failed to start within $timeout seconds"
            }
        }
        catch {
            Write-Error "Failed to start $($service.Name): $_"
        }
    }
    
    Write-Progress -Activity "Starting OpenHands Nexus" -Completed
    Write-Host "`nAll services started!" -ForegroundColor Green
    Write-Host "Desktop: http://127.0.0.1:8000"
    Write-Host "Mobile:  https://$(Get-LocalIP):8443"
}
```

### Проблема 2: Нет автоматического health-check

**Где:** Отсутствует  
**Что:** Если сервис падает, система не перезапускает его  
**Как исправить — создать `health-check.ps1`:**

```powershell
# health-check.ps1 - автоматический мониторинг
$services = @(
    @{ Name = "llama-swap"; Port = 8080; RestartCommand = "llama-swap --port 8080" },
    @{ Name = "Voice Bridge"; Port = 18002; RestartCommand = "python local-voice/main.py" },
    @{ Name = "Agent Server"; Port = 18000; RestartCommand = "python -m openhands.server" },
    @{ Name = "Agent Canvas"; Port = 8000; RestartCommand = "node openhands-pwa/agent-canvas.js" },
    @{ Name = "LAN Gateway"; Port = 8443; RestartCommand = "node openhands-pwa/gateway.js" }
)

$checkInterval = 30 # секунд
$maxRestarts = 3
$restartCounts = @{}

Write-Host "OpenHands Nexus Health Check started" -ForegroundColor Cyan
Write-Host "Checking every $checkInterval seconds..."

while ($true) {
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    
    foreach ($service in $services) {
        try {
            $connection = Test-NetConnection -ComputerName localhost -Port $service.Port -WarningAction SilentlyContinue
            
            if (-not $connection.TcpTestSucceeded) {
                Write-Warning "[$timestamp] $($service.Name) (port $($service.Port)) is DOWN"
                
                # Проверка лимита перезапусков
                if (-not $restartCounts.ContainsKey($service.Name)) {
                    $restartCounts[$service.Name] = 0
                }
                
                if ($restartCounts[$service.Name] -lt $maxRestarts) {
                    Write-Host "[$timestamp] Attempting to restart $($service.Name)..."
                    $restartCounts[$service.Name]++
                    
                    Start-Process -FilePath $service.RestartCommand.Split(' ')[0] `
                                 -ArgumentList $service.RestartCommand.Split(' ')[1..10] `
                                 -WindowStyle Hidden
                    
                    Start-Sleep -Seconds 5
                }
                else {
                    Write-Error "[$timestamp] $($service.Name) exceeded max restarts ($maxRestarts)"
                    # Отправить уведомление или алерт
                }
            }
            else {
                Write-Host "[$timestamp] $($service.Name) (port $($service.Port)) is OK" -ForegroundColor Green
                $restartCounts[$service.Name] = 0 # Сброс счётчика при успешной работе
            }
        }
        catch {
            Write-Error "[$timestamp] Error checking $($service.Name): $_"
        }
    }
    
    Start-Sleep -Seconds $checkInterval
}
```

```python
# monitoring/vram_monitor.py
import pynvml
import time
import json
from datetime import datetime

class VRAMMonitor:
    def __init__(self):
        pynvml.nvmlInit()
        self.handle = pynvml.nvmlDeviceGetHandleByIndex(0)
    
    def get_vram_info(self):
        info = pynvml.nvmlDeviceGetMemoryInfo(self.handle)
        return {
            'total_mb': info.total // (1024 * 1024),
            'used_mb': info.used // (1024 * 1024),
            'free_mb': info.free // (1024 * 1024),
            'utilization_percent': (info.used / info.total) * 100
        }
    
    def get_model_memory_usage(self):
        """Получить использование памяти по процессам"""
        processes = pynvml.nvmlDeviceGetComputeRunningProcesses(self.handle)
        return [
            {
                'pid': p.pid,
                'memory_mb': p.usedGpuMemory // (1024 * 1024) if p.usedGpuMemory else 0
            }
            for p in processes
        ]
    
    def log_to_file(self, filepath='logs/vram.log'):
        info = self.get_vram_info()
        timestamp = datetime.now().isoformat()
        with open(filepath, 'a') as f:
            f.write(f"{timestamp}: {json.dumps(info)}\n")
    
    def check_thresholds(self, warning_threshold=80, critical_threshold=95):
        info = self.get_vram_info()
        if info['utilization_percent'] >= critical_threshold:
            return 'CRITICAL', info
        elif info['utilization_percent'] >= warning_threshold:
            return 'WARNING', info
        return 'OK', info

# Использование

        status, info = monitor.check_thresholds()
        print(f"[{status}] VRAM: {info['used_mb']}/{info['total_mb']} MB ({info['utilization_percent']:.1f}%)")
```

### Проблема 2: Нет кэширования ответов моделей

**Где:** Отсутствует  
**Что:** Повторяющиеся запросы обрабатываются заново  
**Как исправить:**

```python
# cache/semantic_cache.py
import hashlib
import json
import sqlite3
from datetime import datetime, timedelta
from typing import Optional, Dict, Any
import numpy as np

class SemanticCache:
    def __init__(self, db_path='cache/responses.db', ttl_hours=24):
        self.db_path = db_path
        self.ttl = timedelta(hours=ttl_hours)
        self.init_db()
    
    def init_db(self):
        conn = sqlite3.connect(self.db_path)
        conn.execute('''
            CREATE TABLE IF NOT EXISTS cache (
                key TEXT PRIMARY KEY,
                query_hash TEXT,
                query_text TEXT,
                response TEXT,
                model TEXT,
                created_at TIMESTAMP,
                hits INTEGER DEFAULT 0
            )
        ''')
        conn.commit()
        conn.close()
    
    def _get_query_hash(self, query: str, model: str) -> str:
        """Создать хеш запроса для поиска"""
        normalized = query.lower().strip()
        return hashlib.sha256(f"{normalized}:{model}".encode()).hexdigest()
    
    def get(self, query: str, model: str) -> Optional[Dict[str, Any]]:
        """Получить кэшированный ответ"""
        query_hash = self._get_query_hash(query, model)
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        cursor.execute('''
            SELECT response, created_at FROM cache 
            WHERE query_hash = ? AND created_at > ?
        ''', (query_hash, datetime.now() - self.ttl))
        
        result = cursor.fetchone()
        
        if result:
            # Увеличить счётчик попаданий
            cursor.execute('UPDATE cache SET hits = hits + 1 WHERE query_hash = ?', (query_hash,))
            conn.commit()
            conn.close()
            return json.loads(result[0])
        
        conn.close()
        return None
    
    def set(self, query: str, model: str, response: Dict[str, Any]):
        """Сохранить ответ в кэш"""
        query_hash = self._get_query_hash(query, model)
        conn = sqlite3.connect(self.db_path)
        
        conn.execute('''
            INSERT OR REPLACE INTO cache 
            (key, query_hash, query_text, response, model, created_at, hits)
            VALUES (?, ?, ?, ?, ?, ?, 0)
        ''', (
            query_hash,
            query_hash,
            query,
            json.dumps(response),
            model,
            datetime.now()
        ))
        
        conn.commit()
        conn.close()
    
    def cleanup_expired(self):
        """Удалить устаревшие записи"""
        conn = sqlite3.connect(self.db_path)
        conn.execute('DELETE FROM cache WHERE created_at < ?', (datetime.now() - self.ttl,))
        conn.commit()
        conn.close()
    
    def get_stats(self) -> Dict[str, Any]:
        """Получить статистику кэша"""
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        cursor.execute('SELECT COUNT(*), SUM(hits) FROM cache')
        total, hits = cursor.fetchone()
        
        conn.close()
        
        return {
            'total_entries': total or 0,
            'total_hits': hits or 0,
            'hit_rate': (hits / total * 100) if total else 0
        }

# Использование в LLM router
from cache.semantic_cache import SemanticCache

cache = SemanticCache()

async def get_llm_response(query: str, model: str) -> Dict[str, Any]:
    # Проверить кэш
    cached = cache.get(query, model)
    if cached:
        cached['from_cache'] = True
        return cached
    
    # Получить новый ответ
    response = await call_llm_model(query, model)
    
    # Сохранить в кэш
```

```javascript
// pwa/websocket-client.js
class RealtimeClient {
    constructor(url) {
        this.url = url;
        this.ws = null;
        this.reconnectAttempts = 0;
        this.maxReconnectAttempts = 5;
        this.reconnectDelay = 1000;
        this.listeners = new Map();
    }
    
    connect() {
        this.ws = new WebSocket(this.url);
        
        this.ws.onopen = () => {
            console.log('WebSocket connected');
            this.reconnectAttempts = 0;
            this.emit('connected');
        };
        
        this.ws.onmessage = (event) => {
            const data = JSON.parse(event.data);
            this.emit(data.type, data.payload);
        };
        
        this.ws.onclose = () => {
            console.log('WebSocket disconnected');
            this.emit('disconnected');
            this.attemptReconnect();
        };
        
        this.ws.onerror = (error) => {
            console.error('WebSocket error:', error);
            this.emit('error', error);
        };
    }
    
    attemptReconnect() {
        if (this.reconnectAttempts < this.maxReconnectAttempts) {
            this.reconnectAttempts++;
            const delay = this.reconnectDelay * Math.pow(2, this.reconnectAttempts - 1);
            
            console.log(`Reconnecting in ${delay}ms (attempt ${this.reconnectAttempts})`);
            
            setTimeout(() => {
                this.connect();
            }, delay);
        }
    }
    
    subscribe(event, callback) {
        if (!this.listeners.has(event)) {
            this.listeners.set(event, new Set());
        }
        this.listeners.get(event).add(callback);
    }
    
    unsubscribe(event, callback) {
        if (this.listeners.has(event)) {
            this.listeners.get(event).delete(callback);
        }
    }
    
    emit(event, data) {
        if (this.listeners.has(event)) {
            this.listeners.get(event).forEach(callback => callback(data));
        }
    }
    
    send(type, payload) {
        if (this.ws && this.ws.readyState === WebSocket.OPEN) {
            this.ws.send(JSON.stringify({ type, payload }));
        }
    }
}
```

```python
# utils/logger.py
import logging
import logging.handlers
import os
from datetime import datetime
from pathlib import Path

class OpenHandsLogger:
    def __init__(self, log_dir='logs', max_size_mb=10, backup_count=5):
        self.log_dir = Path(log_dir)
        self.log_dir.mkdir(exist_ok=True)
        
        self.max_bytes = max_size_mb * 1024 * 1024
        self.backup_count = backup_count
        
        self.loggers = {}
    
    def get_logger(self, name: str) -> logging.Logger:
        if name in self.loggers:
            return self.loggers[name]
        
        logger = logging.getLogger(name)
        logger.setLevel(logging.DEBUG)
        
        # Файловый обработчик с ротацией
        log_file = self.log_dir / f'{name}.log'
        file_handler = logging.handlers.RotatingFileHandler(
            log_file,
            maxBytes=self.max_bytes,
            backupCount=self.backup_count,
            encoding='utf-8'
        )
        file_handler.setLevel(logging.DEBUG)
        
        # Консольный обработчик
        console_handler = logging.StreamHandler()
        console_handler.setLevel(logging.INFO)
        
        # Форматтеры
        file_formatter = logging.Formatter(
            '%(asctime)s | %(name)s | %(levelname)-8s | %(funcName)s:%(lineno)d | %(message)s'
        )
        console_formatter = logging.Formatter(
            '%(asctime)s | %(levelname)-8s | %(message)s',
            datefmt='%H:%M:%S'
        )
        
        file_handler.setFormatter(file_formatter)
        console_handler.setFormatter(console_formatter)
        
        logger.addHandler(file_handler)
        logger.addHandler(console_handler)
        
        self.loggers[name] = logger
        return logger
    
    def get_audit_logger(self) -> logging.Logger:
        """Отдельный логгер для аудита безопасности"""
        logger = logging.getLogger('audit')
        logger.setLevel(logging.INFO)
        
        if not logger.handlers:
            log_file = self.log_dir / 'audit.log'
            handler = logging.handlers.RotatingFileHandler(
                log_file,
                maxBytes=self.max_bytes,
                backupCount=self.backup_count
            )
            formatter = logging.Formatter(
                '%(asctime)s | AUDIT | %(message)s'
            )
            handler.setFormatter(formatter)
            logger.addHandler(handler)
        
        return logger
```

```python
import logging

class VoiceError(Enum):
    NO_AUDIO = "no_audio"

    TIMEOUT = "timeout"
    MICROPHONE_ERROR = "microphone_error"
    MODEL_ERROR = "model_error"

    def __init__(self):
        self.logger = logging.getLogger('voice-error-handler')
        self.error_callbacks = []
        self.confidence_threshold = 0.7
    
    def add_error_callback(self, callback: Callable):
        self.error_callbacks.append(callback)
    
    def handle_recognition_result(self, result) -> Optional[str]:
        """Обработать результат распознавания"""
        
        if result is None:
            self._notify_error(VoiceError.NO_AUDIO, "Аудио не получено")
            return None
        
        if not hasattr(result, 'text') or not result.text:
            self._notify_error(VoiceError.LOW_CONFIDENCE, "Речь не распознана")
            return None
        
        if hasattr(result, 'confidence') and result.confidence < self.confidence_threshold:
            self._notify_error(
                VoiceError.LOW_CONFIDENCE,
                f"Низкая уверенность распознавания: {result.confidence:.2f}"
            )
            # Можно запросить подтверждение у пользователя
            return self._request_confirmation(result.text)
        
        return result.text
    
    def _request_confirmation(self, text: str) -> Optional[str]:
        """Запросить подтверждение распознанного текста"""
        # Отправить в UI запрос подтверждения
        # Вернуть текст если подтверждён, иначе None
        return text
    
    def _notify_error(self, error_type: VoiceError, message: str):
        """Уведомить об ошибке"""
        self.logger.warning(f"Voice error [{error_type.value}]: {message}")
        
        for callback in self.error_callbacks:
            try:
                callback(error_type, message)
            except Exception as e:
                self.logger.error(f"Error in error callback: {e}")
```

```python
# config/model_loader.py
import yaml
from dataclasses import dataclass
from typing import List, Dict, Optional
from pathlib import Path

@dataclass
class ModelConfig:
    id: str
    name: str
    role: str
    description: str
    endpoint: str
    vram_limit_gb: int
    thinking_levels: List[Dict[str, int]]

@dataclass
class TeamConfig:
    id: str
    name: str
    models: List[str]
    thinking_level: str

class ModelLoader:
    def __init__(self, config_path: str = 'config/models.yaml'):
        self.config_path = Path(config_path)
        self.models: Dict[str, ModelConfig] = {}
        self.teams: Dict[str, TeamConfig] = {}
        self.load()
    
    def load(self):
        with open(self.config_path, 'r', encoding='utf-8') as f:
            config = yaml.safe_load(f)
        
        # Загрузить модели
        for model_data in config.get('models', []):
            model = ModelConfig(**model_data)
            self.models[model.id] = model
        
        # Загрузить команды
        for team_data in config.get('teams', []):
            team = TeamConfig(**team_data)
            self.teams[team.id] = team
    
    def get_model(self, model_id: str) -> Optional[ModelConfig]:
        return self.models.get(model_id)
    
    def get_team(self, team_id: str) -> Optional[TeamConfig]:
        return self.teams.get(team_id)
    
    def get_models_for_team(self, team_id: str) -> List[ModelConfig]:
        team = self.get_team(team_id)
        if not team:
            return []
        
        return [self.models[model_id] for model_id in team.models if model_id in self.models]
    
    def add_custom_model(self, model_config: ModelConfig):
        """Добавить пользовательскую модель"""
        self.models[model_config.id] = model_config
        self.save()
    
    def save(self):
        """Сохранить конфигурацию обратно в файл"""
        config = {
            'models': [
                {
                    'id': m.id,
                    'name': m.name,
                    'role': m.role,
                    'description': m.description,
                    'endpoint': m.endpoint,
                    'vram_limit_gb': m.vram_limit_gb,
                    'thinking_levels': m.thinking_levels
                }
                for m in self.models.values()
            ],
            'teams': [
                {
                    'id': t.id,
                    'name': t.name,
                    'models': t.models,
                    'thinking_level': t.thinking_level
                }
                for t in self.teams.values()
            ]
        }
        
        with open(self.config_path, 'w', encoding='utf-8') as f:
            yaml.dump(config, f, allow_unicode=True, default_flow_style=False)
```
